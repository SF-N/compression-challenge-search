# Reproducing the ERA5 compression results

This repository contains the code only. The ERA5 arrays are downloaded from the ESiWACE
object store (or replaced by your own data), and all results - `results/`, `results_verified/`,
`results_all/`, `submissions/`, `workflow_cells_official_*.jsonl` - are regenerated by the steps
below (they are git-ignored). Steps 3 and 4 therefore require running step 4's `search.py` and
`finalize.py` first (or copying a results folder from a previous run).

## 1. Environment
See `INSTALL.md` (`requirements-fresh.txt`, then the checker with `--no-deps`).

## 2. Data
```bash
python cache_era5.py pressure single      # -> data/era5/<leveltype>__<var>.npz, challenge timestep 2026-07-15T12:00
```
`era5.py` reads the organizers' kerchunk reference catalogs
(`.../esiwacebucket/ERA5_07_2026/era5_{pressure_50_500_850_1000_202607_3h,single_202607_6h}.grib.refs.json`).
For your own data: any float array of shape `[rows, cols]` or `[levels, rows, cols]` saved as
`data/era5/<leveltype>__<var>.npz` (key `arr`) works with every script below; the requirements
are looked up by `<leveltype>` and GRIB short name `<var>` in compression-recommendations.

## 3. Apply a configuration (no search needed)
```bash
python workflow_config.py pressure z W1 --run        # official cell of a workflow -> codec, ratio, official check
```
* `results/<lk>__<var>.json` — the submitted configuration of every variable (`config`, verified `cr`)
* `workflow_cells_official_{pressure,single}.jsonl` — every (variable, workflow) cell: family, parameter, masks, ratio
* `workflow_config.py` — `config_for`, `cell_to_config`, `config_from_params`, `config_from_table`
* `submissions/*.xlsx` — the scoreboard sheets (configs as text + paste-ready code)

## 4. Re-run the pipeline
| step | script | output |
|---|---|---|
| search the best configuration per variable | `search.py <leveltype> [vars]` | `results/` |
| official verification + Excel sheets | `finalize.py [nproc] [small,pressure,single]` | `results_verified/`, `submissions/` |
| all-timestep rows | `official_all.py`, then `add_alltime_rows.py`, `update_alltime_notes.py` | `results_all/`, sheets |
| the four-workflow cells on the official basis | `workflow_cells_official.py [pressure] [single]` | `workflow_cells_official_*.jsonl` |
| the workflow tables | `make_pressure_table.py pressure|single` | `../ERA5_compression_presentation/*_workflow_table.xlsx` |
| re-check every submitted config on the current data | `audit_submissions.py` | `audit_submissions.jsonl` |

`reqs.py` is the fast mirror of the official checker used inside the bisection; the final
verification always uses `compression_requirement_checks.check_safety_requirements`.
